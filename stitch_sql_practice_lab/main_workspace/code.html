Joins Basics

What / When Gotchas Cheatsheet

A JOIN clause is used to combine rows from two or she more tables, based on a related column between them. Inner joins return records that have matching values in both tables.

SELECT p.product_name, c.category_name
FROM products p
INNER JOIN categories c ON p.category_id = c.id;
